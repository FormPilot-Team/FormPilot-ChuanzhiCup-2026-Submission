# Motion Games Lab

## Register

product

## Users and purpose

50 岁以上、几乎没玩过体感游戏的人：用普通摄像头玩三款森林主题的体感小游戏（摘苹果、林间划船、林间射箭）。支持站着或坐着玩。仅作运动娱乐，不做医疗效果宣称，也不做诊断。

当前状态（2026-10-02，Stage A + B）：独立应用位于 `app/`；摘苹果完整可玩；划船和射箭在首页显示为"敬请期待"。真人试玩待你执行。

## Interaction scope

- **Apple：** 手腕进入苹果 → 停留一会儿 → 摘下；离开后才能摘下一个。苹果只出现在玩家自己演示过的舒适范围内。
- **Boating（下一轮）：** 双臂周期性划动、左右协调、节奏控制；不测肩旋转 ROM。
- **Archery（下一轮）：** READY → DRAW → HOLD → RELEASE 状态机，带躯干和弯肘的防误判。
- **全部游戏：** 躯干侧倾、耸肩的温和提醒；随时一键暂停；看不到人时自动暂停。

## Design constraints

统一的轻量自然系 2.5D 世界，带一点微幻想感：程序化绘制的天空、山、树、草地，加粒子和补间动画；没有 3D 角色或绑定，没有来源不明的素材；音效用 WebAudio 合成。界面大字、少字、目标大、节奏慢；失败不扣分，连击只加分。技术信息只出现在 `?debug=1` 的开发面板里。

## Accessibility

按钮有文字标签，可用键盘操作（空格 / P / Esc 暂停）；状态同时用文字表达，不只靠颜色；左右手用两种颜色加"左/右"字样区分；遵守"减少动画"的系统设置。
