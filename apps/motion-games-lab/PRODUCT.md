# Motion Games Lab

## Register

product

## Users and purpose

50 岁以上、几乎没玩过体感游戏的人：用普通摄像头玩三款森林主题的体感小游戏（摘苹果、林间划船、林间射箭）。支持站着或坐着玩。仅作运动娱乐，不做医疗效果宣称，也不做诊断。

当前状态（2026-10-02，Stage C–E）：独立应用位于 `app/`；三款游戏都能从首页一路玩到结果页。正式界面用左右两只小手光标表达体感控制，不再显示人物描边。真人试玩效果尚未验证。

## Interaction scope

- **共同的手部语言：** 左手青色、右手橙色，手掌上印"左/右"。三种手势：张开（跟随）、半握（正在做动作）、握紧（动作完成的一瞬间）。小手画在手掌中心，判定也用同一个点。
- **Apple：** 手接近苹果 → 苹果发光；手进入苹果 → 小手半握、金色圆环转动；圆环满 → 小手握紧、苹果飞进篮子。离开后才能摘下一个。苹果只出现在玩家自己演示过的舒适范围内。
- **Boating：** 两手轮流向外侧划开再收回（方案 A）。每划一下船向前；左右交替、节奏稳定时"顺流"加速；水面花灯在船边等一会儿，用那一侧的手划一下就能收下。只按二维轨迹判断划水，不测、不显示肩关节旋转角度。
- **Archery：** READY → DRAW → HOLD → RELEASE → HIT → RESET。双手合在胸前 → 向两边拉开 → 稳住 → 拉弦的手往回一松。命中点由持弓手的晃动、稳住程度和拉开程度决定，没有随机成分。带转身、持弓手臂弯曲、只动手腕、手太低的防误判。
- **全部游戏：** 躯干侧倾、耸肩的温和提示（小提示条，不挡画面）；随时一键暂停；看不到人时自动暂停、回来后自动继续；统一的结果页（得分、完成数、成功率/命中率、最多连击、时长、动作稳定性）。

## Design constraints

统一的轻量自然系 2.5D 世界，带一点微幻想感：程序化绘制的天空、山、树、草地、河流、靶场，加粒子和补间动画；没有 3D 角色或绑定，没有来源不明的素材；音效用 WebAudio 合成。界面大字、少字、目标大、节奏慢；失败不扣分，连击只加分。技术信息、骨架、人物描边只出现在 `?debug=1` 里。

## Accessibility

按钮有文字标签，可用键盘操作（空格 / P / Esc 暂停）；状态同时用文字表达，不只靠颜色；左右手用两种颜色加"左/右"字样区分；射箭可选左手或右手拉弦；遵守"减少动画"的系统设置。
