## 1. 架构与版本

```
请求（与 P0 相同）──► P0 规则服务（不变，始终可回退）
宿主可信输入：DecisionState（画像 + Reader 历史/报告，缺失即 missing）、可用性快照
  ▼ 前置门禁：请求 / 画像 / 风险暂停 → 不调用模型
  ▼ 安全候选池：P0 同款过滤 + 实测注意项并集 + 可用性（只删不加）
  ▼ 第一阶段检索（K=12）：P0 结果 + PR #49 结果 + PR #49 效用补足（与训练候选池的构造方式一致）
  ▼ 第二阶段 fp-cdm-m2：111 个特征（P 画像×内容 / H 历史×内容 / R 报告×内容，含 M1 内容特征）→ 线性成对偏好分
  ▼ 校准：Platt → 适配概率；成对温度 → top-1 置信度
  ▼ 弃权：最高适配概率 < τ，或 top-1 的特征超出训练范围（±25%）→ ABSTAIN → 规则
  ▼ 独立 Guard（自行重算安全池）→ 违规 → 规则
  ▼ off（默认）/ shadow / active；executedActions = false
```

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| M1 `fp-cdm-m1` | v1.0（HGB，非嵌套）、**v1.1（嵌套 LOPO 选择程序；可部署配置为 v1 特征 / HGB 深度 2）** | M2 使用 v1.0 的 out-of-fold 内容特征（依预先声明的采纳规则，见 §4.3） |
| M2 `fp-cdm-m2` | 权重 v1.0（pairwise LR，C = 0.01）；**运行时 v1.1.0**（加入检索与新的 OOD 规则） | 内置权重为 `AWAITING_LABELS` 占位；AI 标签权重只用于实验，加载器拒绝 |
| 特征集 | `fp-cdm-features/v1` | TS 单一实现，训练导出与浏览器推理共用 |
| 借鉴 StartLux | 状态与缺失语义、决策 / 执行解耦、结构化协议、验证集温度校准、ABSTAIN 原因码、独立 Guard、模型身份与哈希、shadow / active | 未使用其权重、标签、训练数据或 24/126 偏差 |

## 3. M1 内容理解模型

- 任务：用窗口级姿态特征预测章节的部位标签与注意标签。章节得分 = 窗口概率的均值（部位）或 90 百分位（注意项），聚合方式预先声明。
- 协议：**嵌套按功法留一**。外层留出整套功法；内层只在其余 3 套功法上做留一，选择特征集（v1 / v2）、模型族（LR / HGB / ExtraTrees）和超参数。
- 结果（9 个可学习标签的宏平均 AUC）：
  - M1 v1.1（嵌套）**0.777**（部位 0.748，注意项 0.813）；v1.0（HGB，非嵌套）0.761；PR #49 手工描述符 0.737；差值的 bootstrap CI 为 [−0.020, 0.091]。
  - 按留出功法：八段锦 0.785｜太极拳 **0.606**（最难）｜五禽戏 0.811｜易筋经 0.836。
  - 各标签：肩 0.50，颈 0.83，上肢 0.79，躯干 0.75，下肢 0.87，过顶 0.77，平衡 0.89，转体 0.68，俯身 0.91；weight_bearing 只有 1 个正例章节，不可学习。
- 负结果：新增的 28 个 v2 姿态特征没有带来提升（最好的 v2 配置 0.743，v1 为 0.791），未采用。
- 鲁棒性（只扰动测试特征，5 个种子）：无扰动 0.791｜噪声 0.1 / 0.25 / 0.5 SD：0.792 / 0.779 / 0.755｜特征缺失 20% / 40%：0.751 / 0.680。

## 4. M2 偏好排序模型

### 4.1 训练与选择

- 特征 111 个（P 95 / H 11 / R 5），只保留在同一用户的候选之间变化的特征；缺失的历史或报告对应特征为 0。
- 在 18 个开发族上做 6 折分组交叉验证。预先声明只选线性模型（浏览器可运行），HGB 只作离线对照。选中 pairwise LR，C = 0.01。
- 校准：成对温度 T = 0.90；Platt 只在开发集 OOF 上拟合；弃权阈值 τ = 0.842（top-1 精度 ≥ 0.85）。
- 流水线对照：植入的随机隐藏信号能学到（测试 NDCG@5 0.88）；随机标签学不到（0.51），未发现泄漏。

### 4.2 冻结测试（单次，6 个族 / 18 个场景，AI 标签）

| 系统 | NDCG@3 | NDCG@5（95% CI） | P@3 | R@5 | 成对准确率 |
| --- | --- | --- | --- | --- | --- |
| 规则 P0 | 0.736 | 0.819（0.738–0.886） | 0.722 | 0.669 | 0.707 |
| PR #49 手工权重 | 0.770 | 0.797（0.723–0.849） | 0.759 | 0.625 | 0.732 |
| **fp-cdm（P+H+R）** | 0.811 | **0.868**（0.738–0.959） | 0.889 | 0.763 | **0.873** |

模型 − P0 的 NDCG@5 差值 CI 为 [−0.024, 0.122]，模型 − PR #49 为 [−0.090, 0.174]，NDCG 优势**不显著**。成对准确率的差距较大。测试集只评测过这一次。

### 4.3 开发集研究（只用开发族；冻结测试不参与）

- 消融（NDCG@5）：
  - 规则 P0 0.810｜PR #49 0.774｜学习的 3 个基础特征 0.788；
  - 只用交叉特征 0.855｜画像×内容但不含 M1 0.876｜加入 M1 0.890｜+历史 0.894｜+历史+报告 **0.897**｜全部特征但去掉 M1 0.881。
  - **M1 内容特征约贡献 +0.015**；历史、报告的贡献都很小（+0.004、+0.003）。
- 学习曲线：训练族数 3 → 15 时，NDCG@5 从 0.827 升到 0.897，仍在上升。
- 标签噪声：训练标签有 10% / 20% / 30% 被 ±1 扰动时，NDCG@5 为 0.879 / 0.871 / 0.880。
- 校准：ECE 0.032，Brier 0.161。由于标签中没有 0 分，低适配弃权几乎不会触发。
- 跨功法排序（训练时去掉某功法，再为该功法的内容排序）：八段锦 0.951（规则 0.926 / PR #49 0.950）、太极拳 0.957（0.953 / 0.916）、五禽戏 1.000（0.938 / 1.000）、易筋经 0.962（0.941 / 0.928）。
- 采纳规则（预先声明）：用 M1 v1.1 特征的 M2 在开发集上为 0.883，低于 0.897 − 0.005，**未采纳**；也因此冻结测试无需第二次评测。

### 4.4 个性化（E2，22,320 个冷启动画像）

| | 不同推荐组合 | 归一化熵 | 所选部位平均覆盖 |
| --- | --- | --- | --- |
| 规则 P0 | 57 | 0.198 | 0.822 |
| PR #49 | 433 | 0.402 | 0.823 |
| fp-cdm | 360 | 0.302 | **0.845** |

fp-cdm 在 2,133 个画像（9.6%）上弃权，主要是选择了训练中没见过的部位数量（例如 5 个部位全选时 `x_region_overlap` = 4，而训练范围是 0–3），随后回退规则。

### 4.5 误差分析

- 冻结测试中有 4/18 个场景的 top-1 不是最高分（F04-A，F10-A/B/C）。
- 解释面板暴露出模型的捷径：在全目录 58 项上排序时，“内容含颈部”这样的内容先验会主导与颈部无关的用户。这是训练（池化候选）与推理（全目录）不一致造成的。由此加入第一阶段检索（运行时 1.1.0），E1 的评测设置与之相同。
- 旧的 OOD 规则（全池 8σ 计数）会被罕见但已见过的二值特征误触发，6 个典型画像中有 4 个误弃权。已改为“top-1 超出训练范围”，现在 6 个中 5 个给出推荐，剩下的 1 个属于真正的分布外。

## 5. 安全与性能（E4 / E5）

- 风险画像 13,392/13,392 全部暂停，模型执行 0 次；受限画像 caution 泄漏 0；不可启动章节 0；对抗性“偏好风险内容”的权重下，6,572 个受限画像的泄漏为 0；不可用内容被推荐 0；分布外、低适配、未训练时都能正确回退。
- 推理（运行时 1.1.0，AI 实验权重，CPU 单线程）：p50 0.99 ms / p95 2.16 ms；批量 1.29 ms/次；打包后冷启动导入 3.8 ms + 首次调用 7.3 ms；堆内存 4.8 MB；参数 337 个（另有 222 个范围值）；入口包含规则代码，约 139 KB min / 36 KB gzip；不用 GPU，不联网。

## 6. Coach Decision Lab

`scripts/decision-model/cdm/lab/build-lab.mjs` 生成离线单文件 HTML，真实模块在浏览器内运行。页面包括：结论状态、数据卡、实时决策（场景或自定义画像，含风险与可用性开关）、“为什么”面板、典型画像对照、训练过程、实验结果、跨功法泛化、安全与性能、局限与启用条件。AI 标签实验页带水印，非人工权重不加 `--ai-label-experiment` 或 `--fixture-preview` 时生成器会拒绝。

## 7. 复现

见 `scripts/decision-model/cdm/README.md`。全部脚本只读仓库数据；Python 用本机 3.12 + scikit-learn 1.8（`-I -B`），TS 用 vite-node。

## 8. 尚未解决的问题

1. M2 没有人工标签：无法给出人工一致性、专家判断或真实用户层面的结论。
2. 标签只用了 1–3 三个等级，弃权阈值几乎不起作用；场景中历史 / 报告变化的影响较弱，E3 的检验力有限。
3. AI 标注者与 PR #49 的设计者为同一智能体，基线对照存在偏差风险（与 P0 的相关 ρ 0.445，与 PR #49 0.413）。
4. 测试集只有 6 个族；M1 只有单一示范者、4 套功法，太极拳泛化最弱。
5. 游戏没有姿态描述符，也没有历史记录持久化。

3. Web 负责人先以 shadow 模式接线，核对来源文案；active 模式、合并 main、修改安全门禁，均由负责人决定。
