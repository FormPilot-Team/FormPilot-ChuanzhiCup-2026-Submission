# E4 · MediaPipe 关键点时序识别对照

本轮只使用现有 MediaPipe 的 33 个关键点。正式识别新增短遮挡连续性检查；多阶段匹配保留为隔离原型。

## 同源对照

`tests/workshop-temporal.test.ts` 把同一组合成关键点帧分别送入 E2 规则（关闭短遮挡恢复）和 E4 规则（开启恢复），按完整计次数比较：

| 输入序列 | E2 | E4 | 判定 |
| --- | ---: | ---: | --- |
| 正常完整往返，0.5× / 1× / 1.5× | 1 / 1 / 1 | 1 / 1 / 1 | 不因速度变化漏计 |
| 到位期间约 0.1 秒遮挡，恢复时姿势连续 | 0 | 1 | 恢复短遮挡 |
| 遮挡后从到位直接跳回起点 | 0 | 0 | 不跨未知轨迹拼接计次 |
| 未到位、反向起步、明显偏离示范轨迹 | 不作为改进目标 | 0 | 保留拒绝行为 |

E4 规则只对按示范姿势计次启用：遮挡不超过 150 毫秒，且恢复时姿势进度与遮挡前相差不超过 0.3，才接着识别；否则重新从起点开始。模板计次、持续保持和旧动作数据格式不变。

`ThreeStagePrototype` 使用开始、中间、完成三个姿势，按“开始→中间→完成→中间→开始”的顺序检查。合成序列可计 1 次；跳过中间或完成姿势计 0 次。当前动作存储格式没有中间姿势字段，因此原型未接入正式训练，也未更改旧动作库。

## 证据边界与后续验收

- 上述数值来自确定性的合成关键点序列，不是独立真人视频、硬件或临床效果评价。
- 150 毫秒和 0.3 进度阈值尚未用不同摄像头、遮挡位置和动作类型校准；需要真实视频对照误计、漏计与延迟。
- 多阶段原型只有阶段顺序验证，尚无持久化、创建界面或实际训练验证，不应作为已交付的多阶段识别功能。
