# 侧平举规格落地

本文件记录 Phase 1 对高优先级《AI 电子教练核心动作规则规格 v1.0》的工程映射。当前仅实现侧平举；Step Jack、深蹲和提膝不进入规则代码。

## 预处理

- 侧平举必需点：左右肩、肘、腕、髋；画面完整度额外检查膝、踝。
- 可见度阈值：`0.65`。
- 滤波：最近 `5` 帧逐关键点中值，然后 EMA，`alpha = 0.35`。
- 尺度锚点：肩宽、髋宽、躯干长度在 `DerivedBodyPoints` 中统一派生。
- 状态切换须连续满足 `5` 帧；单帧尖峰不切换。

## 状态机

| 当前阶段 | 条件 | 下一阶段 |
|---|---|---|
| START | 平均肩角 `> 25°` 且速度 `> 6°/s` | RAISING |
| RAISING | 平均肩角 `>= 75°` 且速度 `<= 24°/s` | TOP |
| TOP | 速度 `< -6°/s` | LOWERING |
| LOWERING | 平均肩角 `<= 20°` | COMPLETE |

完成一次后只发出一帧 `completedRep`，包含峰值肩角、最小肘角、最大左右差、最大躯干倾斜、顶部停留和总耗时；随后回到 START 并保留计数。

## 判定阈值

| 项目 | 理想/阈值 | 规则输出 |
|---|---|---|
| 顶部肩角 | `80–100°` | 低于 80°：`ARM_TOO_LOW_L/R` |
| 肘角 | `>= 150°` | `ELBOW_TOO_BENT_L/R` |
| 左右峰值差 | `<= 15°` | `ASYMMETRY` |
| 躯干倾斜 | `<= 10°` | `TORSO_LEAN` |
| 顶部停留 | `200–800 ms` | 进入节奏指标与调试观察 |
| 单次周期 | `2000–4000 ms` | 小于 2000 ms：`TOO_FAST` |
| 未完成超时 | `6000 ms` | `INCOMPLETE_REP` |

姿态/画面错误会门控其他纠错，避免关键点不可靠时误导用户。反馈优先级：姿态/入镜 > 手臂过低 > 不对称 > 肘部 > 躯干 > 节奏 > 未完成。

## 评分

评分连续而非只按通过/失败离散跳变：

- 幅度 35%
- 对称 25%
- 稳定 20%
- 节奏 10%
- 完整 10%

理想区间内满分，偏离后按线性 falloff 递减；规则判定仍使用明确阈值，便于解释和调参。画面/姿态无效时所有指标标为 invalid，总分为 0。

## 反馈防抖

- 错误持续 `350 ms` 后才发纠正（规格约 330 ms，工程取整到 350 ms）。
- 错误消失持续 `500 ms` 后才发恢复反馈。
- 同一反馈冷却 `4000 ms`。
- 不同反馈至少间隔 `1500 ms`。
- 每个输出帧只选择排序后的第一条作为主反馈。

## 规格冲突裁决

初版规则文档给出的顶部停留为 `0.2–0.6 s`，核心动作规则规格给出 `0.2–0.8 s`。按项目要求的优先级，采用核心规格 `0.2–0.8 s`。产品文档中的页面与技术建议作为体验约束，不覆盖核心动作阈值。
