# 真人校准协议

## 隐私边界

Calibration Mode只在内存中记录匿名骨点派生角度、比例、时序、阶段、评分和规则结果；不保存视频、照片、原始摄像头帧或身份信息。用户主动点击“导出JSON/CSV”后才下载数据。

## 测试覆盖

每组至少覆盖不同身高、臂长、男性/女性、宽松/贴身衣物；环境分别使用正常灯光、较暗灯光、强背景光、不同摄像头高度和远近距离。

侧平举逐项执行：标准动作、右臂偏低、左臂偏低、明显屈肘、左右不对称、身体侧倾、快速甩动、未完全回落、半身出框、手腕短暂遮挡。

Step Jack逐项执行：标准左/右循环、步幅不足、手臂不足130°、手臂先行、脚步先行、连续同侧、躯干侧倾、快速动作、未回CENTER、出框和短暂遮挡。

## 采集步骤

1. 固定浏览器、设备、摄像头分辨率和环境标签；打开 `?debug=1`。
2. 入镜静止3秒，完成每类动作至少10次；不同错误类型分开采集。
3. 每组结束分别导出JSON和CSV，用匿名测试编号命名，不使用姓名。
4. 人工标注每次动作真实类别、期望侧、开始/峰值/结束时间和应触发错误。
5. 将诊断rep与人工标注按时间对齐，计算每类规则的TP/FP/FN、计数误差及阶段延迟。
6. 只有跨用户、跨环境结果稳定后才版本化修改配置；保留原始Engineering V1作为基线。

## 导出字段

逐帧包含timestamp、pose confidence、肩/肘角、对称差、躯干倾斜、openRatio、脚偏移、当前侧、同步差、phase/transition、rep index、score、errors和primary feedback。逐rep包含start/top/end、峰值肩角、最小肘角、最大对称差/侧倾、duration、final score，以及Step Jack侧别/峰值openRatio/sync gap。

本阶段没有真人数据，因此不得声称统计准确率。
