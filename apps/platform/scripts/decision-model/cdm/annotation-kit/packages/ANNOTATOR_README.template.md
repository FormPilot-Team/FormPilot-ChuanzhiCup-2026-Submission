## 要做什么

- 共 18 个用户场景，每个场景 8–12 个候选训练内容（功法章节或体感游戏）。逐个打 0–3 分，约 180 条，15–20 分钟。

## 步骤

1. 先读 `GUIDELINES.md`（约 5 分钟），重点是第 3 节的分级表。
2. 用 Edge 或 Chrome 打开 `fp-cdm-annotation-v1-testfamilies.html`。不需要联网。
3. 首页“标注者登记（匿名）”：“编号”填 `{{ID}}`；“背景”选“团队成员（非临床）”；“相关年限”填与功法练习、康复或运动指导相关的经验年数，没有就填 0。然后点“开始 / 继续”。如果你参与过目录标签或推荐规则的编写，在第一个场景第一项的“备注”里写明。
4. 逐个场景打分。认为某项内容对这个用户可能不安全时，勾选“安全疑虑”（可以同时给 0 分）。
5. 全部完成后点“导出 JSON”，得到 `fp-cdm-labels-v1-{{ID}}.json`。
6. 把这个文件**私下直接发给负责人**。不要发到群里，也不要发给另一位标注者。
