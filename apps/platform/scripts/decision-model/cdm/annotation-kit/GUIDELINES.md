# fp-cdm 标注规范 v1：训练内容适配度分级

用途：为 FormPilot AI Coach 的成对偏好排序模型提供**独立人工标签**。标注结果是唯一的排序监督信号；不使用规则输出、PR #49 输出或开发者编写的 persona。

## 1. 标注者要求与登记

- 需要 **2 名标注者独立完成**，标注期间不交流、不查看对方结果。另安排 1 名仲裁者（可以是第三人，也可以是两人讨论后由负责人确认）。
- 优先人选：康复医师/治疗师、运动医学或体育教育背景、健身气功指导员。若为团队成员，必须如实登记，结果将标注为“团队标注者（非临床专家）”。
- 工具首页登记匿名编号（A1、A2…）、背景类别和相关年限，不填写姓名或联系方式。

## 2. 每个场景显示什么

- **用户画像**（自述）：目标、困难、关注部位、偏好。风险项均为“无”；急性风险由安全规则直接暂停，不进入标注。
- **训练历史**（部分场景）：练过的章节、次数与完成情况、最近一次距今天数、跟练相似度均分及趋势、游戏记录。
- **最近报告**（部分场景）：报告指出的待关注分项。
- **候选内容**：8–12 项，均已通过现有安全筛选；顺序随机，不显示任何系统的排序或分数。

所有用户、历史和报告都是**合成设计**，不是真实个人。请把它们当作真实咨询对象来判断。

## 3. 分级（对每个候选独立打分）

| 分数 | 含义 | 判断要点 |
| --- | --- | --- |
| **3 非常适合** | 应优先推荐 | 直接对应所选部位与目标；负荷和复杂度适合其困难；有历史/报告时，与之衔接合理（如针对报告问题、在已掌握内容上循序渐进） |
| **2 适合** | 合理选项 | 匹配部位或目标，但衔接、负荷或针对性一般 |
| **1 勉强** | 可以做，但不是好推荐 | 与目标弱相关；负荷或复杂度偏高；重复已充分掌握的内容且无新价值；游戏与需求联系弱 |
| **0 不适合** | 不应推荐 | 与画像明显不符，或你认为对此用户存在安全/适宜性疑虑 |

- **安全疑虑**另有复选框：只要你认为该内容对此用户可能不安全，就勾选（即使已给 0 分）。勾选项会交给 Guard 复核，**不会**用来放宽安全规则。
- 同一场景中可以给多个候选相同分数；不需要强行排出名次。
- 只依据显示的信息判断，不要猜测系统意图。拿不准时用“备注”说明。
- 同一用户会以“仅画像 / 加历史 / 加历史与报告”三种形式出现在不同位置。请按每次显示的信息独立判断，不要回翻对照。

## 4. 质量控制与仲裁

1. 导入后自动计算：二次加权 κ、完全一致率、±1 一致率、逐场景 Spearman。
2. 需要仲裁的情况：两人分差 ≥ 2，或任一方勾选安全疑虑。仲裁者给出最终分并写理由，原始双方分数保留。
3. 最终标签：没有进入仲裁时取两人均值（可以是 .5）；进入仲裁时取仲裁分。安全疑虑项单独汇总，交给安全复核。
4. 若二次加权 κ < 0.4，视为标注标准不一致：先复盘分歧样本并修订规范 v2，重新标注，再进入训练。

## 5. 数据使用与隐私

- 标签只用于本模型研发与评测，按标注者编号存档，不含个人身份信息。
- 划分固定：24 个用户族中，6 个族（18 个场景）为**冻结测试集**，标签返回后只在最终评测时使用一次。
- 模型报告将说明：场景为合成，标签为人工判断，结论只适用于这一合成场景集，不代表真实用户泛化或康复效果。

## 6. 工作量

每人约 720 条评分，约 60–90 分钟。工具自动保存在本机浏览器，可以分次完成；完成后点“导出 JSON”，把文件交给负责人放入 `labels/` 目录。
