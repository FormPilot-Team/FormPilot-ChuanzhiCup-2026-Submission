# FormPilot Coach Decision Model（fp-cdm）说明与实验摘要

发布 `fp-cdm-release/1.0.0`；契约 `fp-coach-decision/v1`；M1 v1.1（内容理解），M2 v1.0.0（偏好排序），运行时 1.2.0。全部在浏览器本地推理，不联网、不调用付费或云端模型。完整报告：仓库 `apps/platform/docs/ai-coach-agent/decision-model/MODEL_REPORT.md`。

## 模型身份（如实展示）

**实验性模型：AI 标注训练，项目负责人已审阅标签，尚未进行独立人工或专家标注。**
M2 的 720 条分级标签来自单一 AI 标注者（72 个合成场景）；2026-11-09 项目负责人审阅后认可用于本竞赛候选模型。这不等同于独立标注者一致性验证或医学专家金标准；权重层级仍为 `ai_experimental`，人工验证状态仍为“待进行”。适配度是“标注者认为适合”的校准概率，不是医学概率。

## 两级模型

| 模型 | 输入 | 作用 |
| --- | --- | --- |
| M1 内容理解 | 标准示范的参考姿态轨迹（1,677 个 3 s 窗口 × 76 特征） | 预测每章的部位与注意项（过顶、平衡、转体、俯身等），以内容表形式随发布绑定 |
| M2 偏好排序 | 用户 × 内容、历史 × 内容、报告 × 内容共 111 个特征（含 M1 输出） | 在安全候选池内为章节与游戏排序，给出校准适配度与特征贡献 |

## 主要结果（冻结测试只评测一次，6 个族 / 18 个场景）

| 系统 | NDCG@5（95% CI） | 成对准确率 |
| --- | --- | --- |
| 规则 Agent Web P0 | 0.819（0.738–0.886） | 0.707 |
| PR #49 手工权重 | 0.797（0.723–0.849） | 0.732 |
| **fp-cdm M2** | **0.868**（0.738–0.959） | **0.873** |

模型 − 规则的 NDCG@5 差值 95% CI 为 [−0.024, 0.122]，**跨 0，不能宣称模型统计显著优于规则**；标签来自与训练相同的 AI 标注者。

- **M1 内容理解**（嵌套按功法留一，9 个标签宏平均 AUC）：0.777（PR #49 手工描述符 0.737，差值 CI [−0.020, 0.091]）；八段锦 0.785、太极拳 0.606（最难）、五禽戏 0.811、易筋经 0.836。
- **消融**（开发族，配对 bootstrap）：去掉部位匹配 −0.058、形式偏好 −0.039、全部画像交叉 −0.053（均显著）；M1 动作感知 −0.016（不显著）；目标交叉无增益。
- **跨功法泛化**（训练时去掉该功法）：八段锦 0.951、太极拳 0.957、五禽戏 1.000、易筋经 0.962（规则 0.926 / 0.953 / 0.938 / 0.941）。
- **鲁棒性**：标签扰动 10–30% 时 NDCG@5 0.871–0.880；输入扰动 200 次首选不变；M1 特征噪声 0.25 SD 时 AUC 0.779。
- **个性化**（22,320 个冷启动画像）：不同推荐组合 规则 57 / PR #49 433 / 模型 360；所选部位覆盖 0.822 / 0.823 / **0.845**；模型弃权回退 9.6%（低适配 8.7%，分布外 0.9%）。

## 安全与回退（2026-11-09 复跑，与冻结产物一致）

- 风险画像 13,392 / 13,392 暂停，模型执行 0 次；受限画像注意项内容展示 0；对抗权重下展示 0；不可用内容展示 0（E4，逐项与冻结产物相同）。
- 模糊测试 3,007 个畸形输入：0 次抛出，0 次未经批准展示模型。
- 权重缺失 / 篡改 / 版本不符 / 内容表或目录指纹不符 / 推理异常 / Guard 拒绝 → 全部回退规则（单元测试）。
- 分布外（如同时关注 4 个部位）或低适配 → 弃权回退规则；首选章节 0–2 天内刚练过时也会弃权（已知局限）。
- 性能：单次推理开发机 p50 约 1–2 ms，浏览器内无网络请求。
