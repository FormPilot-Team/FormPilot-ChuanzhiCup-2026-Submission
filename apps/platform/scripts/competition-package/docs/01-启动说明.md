# FormPilot Web V1.2.1 · Windows 本地启动说明

## 环境

- Windows 10 / 11，自带 Windows PowerShell 5.1（不需要安装 Node、pnpm、Python）。
- 浏览器：Microsoft Edge 或 Google Chrome（已实测 Edge）。
- 摄像头：训练和体感游戏需要；只浏览页面、看示范视频、使用 AI Coach 不需要。
- 不需要联网：识别、推荐和全部资源都在本机运行。
- **本包不含大模型**（Qwen 模型与 Ollama 有数 GB，不随包分发）。AI 教练的固定五问、M1/M2 推荐和风险暂停不需要模型；只有“自由提问”需要本机模型，见下文“AI 教练自由提问”。

## 启动

1. 完整解压 `FormPilot-Web-V1.2.1.zip`（不要在 ZIP 内直接运行），路径中尽量不要有特殊字符。
2. 双击 `start-formpilot.cmd`。
3. 浏览器会自动打开 `http://localhost:4175/`（FormPilot）；体感游戏服务同时运行在 `http://localhost:5181/`。
4. 演示期间保持黑色窗口打开；关闭窗口即停止服务。

若双击后提示端口被占用：关闭占用 4175 / 5181 端口的程序后重试，或在 PowerShell 中运行
`powershell -NoProfile -ExecutionPolicy Bypass -File start-formpilot.ps1 -PlatformPort 4275 -GamesPort 5281`
（此时游戏中心会显示“尚未接入”，因为竞赛构建固定连接 5181 端口的游戏服务）。

## AI 教练自由提问（大模型，可选）

| 情况 | 自由提问 | 其他功能 |
| --- | --- | --- |
| 普通电脑（只解压本包） | 显示“本地 AI 模型未连接 · 自由提问暂不可用”，输入框禁用。这是设计中的正常降级，不是故障 | 全部可用：固定五问、M1/M2 推荐、风险暂停、训练、功法、工坊、游戏、报告 |
| 已装好模型环境的电脑 | 先双击 `start-formpilot.cmd`，再双击 `ai-coach-local\start-ai-coach-local.cmd`；状态变为“已就绪”后可自由提问（首次载入模型约 40 秒） | 同上 |

模型环境指：Node.js 22.18 及以上；本机 Ollama 0.40.13 正在运行，并已安装 `qwen3:4b-instruct-2507-q4_K_M`（Apache-2.0，固定 digest `0edcdef34593…`）。Ollama 不在默认端口 11434 时，用 `start-ai-coach-local.ps1 -OllamaPort <端口>` 启动。启动器只做检查并启动本机 Bridge（只监听 127.0.0.1:4321，只允许本页面访问），**不下载、不安装、不联网、不需要 API Key**。

自由提问的回答由本机模型调用 5 个只读工具（知识库检索、内容目录、M1/M2 推荐、最近一次记录、近期比较）后生成，先通过安全与证据校验再显示；未通过时显示规则回答并注明原因。读取训练记录需要在对话框单独勾选授权。

## 校验

`SHA256SUMS.txt` 列出了包内每个文件的 SHA-256；ZIP 本身的校验值在同目录的 `FormPilot-Web-V1.2.1.zip.sha256`。PowerShell 校验：`Get-FileHash .\FormPilot-Web-V1.2.1.zip -Algorithm SHA256`。

## 数据与隐私

- 训练记录、AI Coach 画像只保存在当前浏览器（localStorage / 页面内存），不上传。
- 摄像头画面只用于实时识别，不录制、不上传。
- 包内不含任何个人训练记录、密钥、Token 或模型文件。
- 自由提问只连接本机 127.0.0.1:4321；问题和训练记录不发往任何外部服务。
