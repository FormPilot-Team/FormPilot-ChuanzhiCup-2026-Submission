# FormPilot Web V1.0 · 竞赛演示流程（约 8–10 分钟）

准备：双击 `start-formpilot.cmd`；Edge 全屏；摄像头对准演示者，距离约 2.5–3 米，头到脚完整入镜，光线充足。首次打开会出现“使用说明”，可直接演示后关闭。

| 步骤 | 操作 | 讲解要点 |
| --- | --- | --- |
| 1 首页（30 s） | 打开 `/`，展示浮动卡片与今日训练摘要 | 数据全部来自本机真实记录，没有记录时显示 0，不展示演示健康数据 |
| 2 训练中心 → 智能训练（2 min） | 训练中心 → 智能训练 → 自由训练选“侧平举”→ 启用摄像头 → 双手胸前合拢开始 | 摄像头只在此页开启；MediaPipe 浏览器本地识别；实时纠正、语音、暂停手势 |
| 3 报告与历史（1 min） | 完成或结束训练 → 查看报告 → “我的”看历史 | 五维能力缺数据显示“有效数据不足”；趋势只用可比较的记录 |
| 4 功法训练（1.5 min） | 功法训练 → 八段锦 → 播放标准示范 → 第二式“示范”→ 单练 | 标准视频与姿态轨迹实时比对相似度与节奏；可继续下一式 |
| 5 AI Coach（2.5 min） | AI Coach → 开始画像：上肢动作练习 · 肩部僵硬 · 肩部 + 上肢 · 功法与游戏结合 → 风险“未报告” → 勾选了解 → 数据授权选“仅按画像” → 生成推荐 | 训练模型推荐：易筋经 · 韦驮献杵第一势 / 八段锦 · 左右开弓似射雕 / 易筋经 · 出爪亮翅势，游戏 林间射箭、林间划船；展开“模型依据”看特征贡献；适配度不是医学概率；决策模型面板显示模型身份与指纹校验 |
| 5a 授权记录（可选） | 改选“使用本机功法记录”并勾选授权 → 更新推荐 | 数据来源变为“已授权本机记录”。若首选章节 0–2 天内刚练过（例如步骤 4 刚练完），模型会按设计弃权并回退规则——这是已知局限，如实说明 |
| 5b 安全 | 把风险改为“当前眩晕或站立不稳”重新生成 | 安全暂停，不推荐任何内容，模型不运行 |
| 5c 回退 | 关注部位选 肩部 + 颈部 + 上肢 + 下肢、暂无不适、功法优先 | 超出训练范围 → 模型弃权，回退规则并说明原因 |
| 6 固定五问与计划（40 s） | 固定五问 → “为什么这样推荐？”；推荐计划 → 开始第 1 项 | 回答来自本次推荐；计划每项可直接开始训练 |
| 7 游戏中心（1 min） | 游戏中心 → 林间射箭 → 开始游戏 → 新窗口游玩 → 关闭窗口 | 游戏在独立应用运行；关闭后回到游戏中心；成绩不计入正式训练 |

## 讲解口径

- 决策模型：实验性模型，AI 标注训练，项目负责人已审阅标签，尚未进行独立人工或专家标注；与规则相比 NDCG 优势的置信区间跨 0。
- 全部在浏览器本地运行，不上传、不联网、不使用付费 API。
- 不做诊断，不宣称疗效。
