# FormPilot Web V1.0 · 产品功能说明

FormPilot 是在浏览器本地运行的 AI 动作训练产品：摄像头实时识别动作并纠正，传统功法跟练与报告，AI Coach 推荐下一步练习，体感游戏增加趣味。界面按 PR #52 / #54 设计稿实现。

## 六大板块

| 板块 | 地址 | 能做什么 | 数据来源 |
| --- | --- | --- | --- |
| 首页 | `/` | 今日训练摘要、继续训练、今日推荐（进入 AI Coach）、最近训练记录；首次使用显示使用说明 | 本机训练记录；无记录时显示 0 与首次使用提示，不显示演示数字 |
| 训练中心 | `/training` | 智能训练（6 个热身动作完整课程）、自由训练（单个动作）、我的动作、动作工坊入口、使用说明、评分依据 | MediaPipe Pose 浏览器本地识别；原有评分规则 |
| 功法训练 | `/routines` | 八段锦、太极拳、五禽戏、易筋经：详情、标准示范视频（可按章节看）、整套或单式跟练、本节报告、继续下一式 | 标准视频 + 姿态轨迹，实时跟练相似度与节奏 |
| 游戏中心 | `/games` | 摘苹果、林间划船、林间射箭：在独立窗口启动，关闭后回到游戏中心；服务未启动时显示“尚未接入” | Motion Games Lab；游戏成绩不计入正式训练 |
| AI Coach | `/coach` | 画像 → 风险确认 → 数据授权 → 推荐功法 / 章节 / 游戏 → 推荐依据 → 固定五问 → 推荐计划 → 直接开始训练 | 决策引擎 `fp-coach-decision/v1`（竞赛构建：训练模型推荐，异常回退规则） |
| 我的 | `/me` | 训练历史（按来源筛选）、报告、训练变化趋势、动作工坊、设备与设置 | 本机记录；趋势只用可靠的完整热身训练，至少 2 次 |

另有：训练报告 `/report/:id`、训练历史 `/history`、动作工坊 `/workshop`（创建 → 记录姿势 → 测试 → 保存 → 训练）、设备与设置 `/me/settings`。

## 训练与报告

- 摄像头只在训练准备页开启；未授权、无摄像头、被占用、模型加载失败都有对应提示。
- 训练中支持暂停 / 继续（按钮、空格、手势），离开画面自动暂停。
- 报告给出完成度、动作规范、跟练相似度、节奏、五维能力；缺少有效数据的维度显示“有效数据不足”，不按 0 分处理；历史对比只在可比较时显示。

## 不做的事

- 不做医学诊断，不宣称康复疗效。
- 没有自由文本大模型聊天、语音识别或任何付费 / 云端模型；AI Coach 只回答固定五问。
- 游戏历史没有正式数据源，不伪造游戏成绩，也不把游戏分数并入训练评分。
