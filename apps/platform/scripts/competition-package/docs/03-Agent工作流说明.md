# FormPilot AI Coach · Agent 工作流说明

```
用户进入 AI Coach（/coach）
  → 画像：训练目标 · 困难 · 关注部位 · 偏好
  → 风险确认：急性疼痛 / 眩晕 / 近期受伤 → 安全暂停，不推荐任何内容
  → “我已了解”勾选（未勾选 → 要求完善画像）
  → 数据读取授权：默认只用画像；勾选后才读取本机功法跟练记录与最近报告分项（只读、不上传）
  → collectLocalDecisionInput(profile, { consent })          // 未授权时不读本机记录
  → recommendCoachDecision(input, { mode, allowExperimentalModel })   // 唯一公开接口，同步、浏览器本地、不联网
      ├─ 输入严格校验（未知字段、目录外 ID、越界数值 → INPUT_INVALID → 规则）
      ├─ 风险画像 → safety_hold（模型不运行）
      ├─ 安全候选池（受限画像排除过顶 / 平衡 / 转体 / 俯身 / 负重注意项）
      ├─ M2 排序（竞赛构建 ACTIVE）→ 校准适配度 → OOD / 低适配弃权
      ├─ 独立 Guard 复核模型输出
      └─ 任一异常（权重缺失 / 指纹不符 / 推理异常 / Guard 拒绝 / 弃权）→ 回退 Agent Web P0 规则推荐
  → 展示：功法章节 · 功法方向 · 体感游戏；每项理由、依据、知识来源；模型身份、适配度、特征贡献、回退原因
  → 固定五问：我适合练什么？先玩哪个游戏？最近主要问题是什么？为什么这样推荐？下一阶段练什么？
  → 推荐计划：按推荐顺序列出，可直接开始
  → 跳转：章节 → /routines/:id/train?form=:chapter；游戏 → /games?game=:id（游戏中心打开对应游戏）
  → 训练结束写入本机记录（/me、/history 可见）
  → 再次进入 AI Coach 并授权 → 引擎读取新的功法记录（trainingHistory: live_local_records）
```

## 运行模式

| 构建 | 模式 | 用户看到 |
| --- | --- | --- |
| 普通开发 / 普通构建 | OFF | 规则推荐 |
| 开发 `?coachMode=shadow` 或 `VITE_COACH_DECISION_MODE=shadow` | SHADOW | 规则推荐 + 标明的开发面板（模型排序不作为推荐） |
| **竞赛构建（本包）** | **ACTIVE + 已批准实验性模型** | 训练模型推荐；弃权或异常时回退规则并说明原因 |

模式只由构建决定，URL、localStorage 或用户操作都不能改变。

## 边界

- 游戏历史：尚无正式数据源，引擎中保持缺失，不伪造。
- 合成演示数据：正式页面不加载；不会把合成数据当作用户记录。
- 计划不跟踪完成情况；完成训练后在“我的”查看真实记录。
- 推荐是运动练习建议，不是诊断或治疗方案。
