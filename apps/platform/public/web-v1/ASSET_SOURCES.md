# Web展示素材来源

此目录的18份图像/透明WebM在2026-11-17公开准备时统一替换为团队自编程序图形，包括四功法卡片、三游戏卡片、工坊与静音图标、数学粒子光球及其poster/背景。固定路径、图片尺寸、格式及关键透明度保持；没有读取原图片像素、视频帧或功法姿态数据。

这些是后续公开整改覆盖层，不是声称历史提交当时已经使用新素材。全部历史旧blob已替换；原始媒体与历史仅保留在Private备份。生成脚本见 `scripts/submission/original_media/`，逐项旧blob、新blob和SHA-256见 `docs/submission/original-media-manifest.json`（路径从仓库根开始）。
