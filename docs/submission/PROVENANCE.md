# 源码来源与开发历史

作品 Web V1.2.3 的开发基线为 `4bf15bf1c71b19f9674703f5816d19fb246d7b3f`，对应比赛仓库的路径导出基线 `e2f487dd5a6d490ce6c3e77fa820c457b0f7f609`。当前作品提交以 `git rev-parse HEAD` 和交付文件清单中的精确 SHA 为准。

比赛仓库保留作品相关路径的真实 Git 历史，以及 `history/web-v12-development` 开发分支。作者、时间和原始提交说明保留；首次从包含其他项目的私有仓库按路径导出，文件树与父关系改变导致 SHA 改变，原签名不随导出有效。[commit-map.txt](commit-map.txt) 提供原提交到导出提交的映射；这份历史不等同于原私有仓库全部应用与分支的历史。

[source-files.json](source-files.json) 固定产品基线文件的 mode/blob。`python scripts/submission/verify_baseline.py` 核验保留产品文件的原始字节，并明确列出便携说明、文档整理及既有测试环境适配。模型权重、标签、实验产物与产品功能实现未因文档整理变更。

源码 ZIP 仅包含当前受跟踪文件。完整的作品相关历史保留在 [Private 仓库](https://github.com/FormPilot-Team/FormPilot-ChuanzhiCup-2026)，评审需取得读取权限。历史中仍有作者个人邮箱及开发环境路径，仓库保持 Private。外部媒体按[素材与许可](ASSETS_AND_LICENSES.md)单独管理。
